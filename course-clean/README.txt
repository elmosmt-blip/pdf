SMT & THT PROCESS ENGINEER — SELF-STUDY COURSE
Статический курс: HTML/CSS/JS, без сервера, без сборки, без интернета.

КАК ОТКРЫТЬ
  Просто дважды кликните index.html — курс откроется в браузере
  (работает и по file://, и через любой статический веб-сервер).

СОДЕРЖАНИЕ
  15 модулей, 92 урока, 734 вопроса с автопроверкой
  (459 в уроках + 275 в банке экзаменов), 38 стандартов
  + 1 документ вендора (AIM Solder), 8 кейсов Toolkit по Board X.
  Каждый урок: теория, разобранный расчёт, реальный дефект, ссылка на источник.
  По каждому модулю — итоговый экзамен (порог прохождения 80%).
  Прогресс считается по «mastered» (лучший результат квиза >= 80%),
  варианты ответов перемешиваются при каждом показе.

ФАЙЛЫ
  index.html                точка входа
  assets/app.js             движок курса (роутер, квизы, экзамены)
  assets/style.css          оформление
  assets/fonts.css          локальные шрифты IBM Plex (без интернета)
  assets/fonts/*.woff2      файлы шрифтов (latin)
  assets/data-embed.js      встроенная копия данных для открытия по file://
  assets/img/*.webp         иллюстрации
  data/*.json               уроки, вопросы, источники, кейсы (используются при http)
  data/meta.json            версия курса, журнал изменений, адрес формы «Report an error»
  data/paths.json           три пути обучения (новичок / технолог / инспектор)
  docs/edition-registry.csv реестр редакций стандартов (вне сборки)
  docs/case-keys.csv        ключи кейсов с формулами (вне сборки)
  REVIEW_CHECKLIST.md       чек-лист рецензии курса

НАВИГАЦИЯ И ДОВЕРИЕ (фаза 7)
  Пути обучения: #/p/ — три маршрута по курсу; выбранный путь помнится
  в браузере, каждый урок показывает «шаг N из M» и следующий урок пути.
  Версия и журнал изменений: #/about/ (и ссылка в низу боковой панели).
  Report an error: ссылка в конце каждого урока и кейса; ведёт на форму из
  data/meta.json -> report.formUrl с параметрами lesson, version, build, url.
  !!! formUrl в поставке — заглушка (REPLACE-WITH-YOUR-FORM-ID): впишите
  адрес своей формы (или заполните report.email — тогда будет mailto:).
  Печать: Ctrl/Cmd+P на уроке даёт чистый документ с версией в подвале.
  Проверка клавиатуры и контраста: node scripts/check-a11y.js

ВНИМАНИЕ
  Если правите data/*.json, пересоберите assets/data-embed.js,
  иначе при открытии по file:// браузер покажёт старую версию данных.
  При выпуске новой версии: обновите data/meta.json (version, date,
  первая запись changelog) — check-integrity требует, чтобы верхняя
  запись журнала совпадала с version.
