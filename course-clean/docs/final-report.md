## 4. Открытые пункты (вне кода)

1. **`data/meta.json → report.formUrl`** — вписать адрес формы (и имена полей в `report.params`), затем `build-embed` + `build`; нота в check-integrity исчезнет. Пользователь делает сам.
2. **Статус уроков** — все 92 помечены `draft` намеренно: метка `reviewed` ставится только по результатам человеческой рецензии (фаза 9, гейт заказчика). Движок показывает баннер черновика, пока статус не изменён.
3. **Текст уроков по-прежнему называет стандарты** (нормативное упоминание источника, без цитирования). С изображений обозначения убраны; если потребуется то же для текста — отдельное решение.
4. **Визуальная проверка печати** выполнена по правилам CSS и палитре, не по PDF-рендеру (в песочнице нет браузера). Рекомендуется один раз распечатать урок с иллюстрацией и таблицей.
