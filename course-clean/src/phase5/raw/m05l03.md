## Fiducials define the coordinate system
A fiducial is the reference feature the vision system uses to locate the board and, at component level, to locate the part relative to the nozzle. Global fiducials usually sit on board edges or panel rails and establish origin, scale and rotation.

Local fiducials sit near dense or fine-pitch components and compensate local warpage, panel bow or thermal expansion. Fiducial quality usually matters more than nominal position: a clean, high-contrast circular or cross fiducial with a stable edge measures better than a poorly defined shape. Check diameter, contrast and placement tolerance against the placement equipment datasheet and the fabrication drawing.

## Board recognition combines support, vision and geometry
Recognition starts when the conveyor or pallet presents the board. The machine may use edge sensors, clamps, pins or vision to find it, and vision-based recognition typically measures two or more fiducials and computes a transformation from machine to board coordinates.

Poor support lets the measured fiducial positions move during placement. A program with the wrong fiducial type, wrong coordinates or wrong panel origin places components consistently in the wrong place. Before production, confirm that support height, clamp force, conveyor speed and fiducial search window match the board type and the machine setup sheet.

## Vision calibration links pixels to coordinates
Vision calibration converts an image measurement into a machine coordinate measurement. Camera calibration fixes the relationship between pixel distance and physical distance, including scale, centre offset and, on some systems, lens distortion. Nozzle or placement calibration fixes the relationship between nozzle centre and measured component centre.

Calibration that is missing, expired or done with the wrong camera, lens, nozzle or lighting lets the machine report a coordinate the component never reached. Check calibration status as part of setup verification, not after a defect appears, and verify interval and pass criteria against the equipment datasheet and the plant calibration procedure.

## Offset is a vector, not a distance
Placement offset usually arrives as X and Y displacement from target, and a single magnitude hides direction: 0.05 mm in X and 0.05 mm in Y is not the same as a 0.07 mm diagonal.

Diagnose with the sign and magnitude of X, Y and rotation. A constant offset across many boards points to board coordinates or calibration. An offset that changes with board position points to support, conveyor or fiducial recognition. An offset that changes with component type points to nozzle, feeder or component vision.

## Skew and rotation are not offset
Skew is angular misalignment against the board coordinate system. Rotation error can appear as a component angle error or as an asymmetric offset between opposite ends of the part, and a component can be centred yet rotated, or displaced because it rotated about a point away from its centre.

Small passives, odd-form parts and parts near board edges, where the vision field of view is limited, rotate most often. Check the acceptable rotation limit against the assembly drawing, the IPC-A-610 class requirements and the footprint geometry.

## Missing, wrong-part and polarity are detected differently
Component vision reports a missing part when it finds nothing at the expected location after placement, and post-placement inspection reports it when it finds an empty footprint.

Wrong-part defects surface through component height, body size, terminal count, marking or feeder configuration. Polarity surfaces through orientation-sensitive features: a dot, chamfer, notch, asymmetric terminal or marking. Feeder setup and program verification prevent some of these, and vision catches others. A missing component can also come from a failed pick, a feeder that did not advance, or a part dropped in transfer.

## Verify program geometry, not only part numbers
A placement program carries part numbers, coordinates, rotation, pick height, place height, nozzle selection, feeder assignment and vision parameters. Verification confirms that the coordinate origin matches the fiducial scheme, that rotation matches the footprint, and that the selected nozzle and feeder are physically installed.

A program can pass a part-number check and still cause defects through wrong fiducial coordinates, a wrong component centre offset, or a vision search window too small. Prove the placement with a dry run or test board before production, especially after a program revision, nozzle change, feeder change or calibration event.

## Calibration status is part of setup
Before production, confirm that camera calibration, nozzle calibration and any component-specific vision calibration are current and inside tolerance. A record that is missing, expired or tied to a different nozzle, camera, lens or feeder leaves the setup unverified.

Missing calibration produces symptoms that look like mechanical drift: a constant X or Y offset, inconsistent rotation, poor repeatability. Stop the setup, perform or confirm the calibration, and re-run a verification board before releasing production.

## Key takeaways
Measure at least two fiducials and verify their coordinates against the drawing, because a board origin error looks exactly like a calibration fault.
Record offset as a signed X and Y vector with rotation, since a magnitude and a direction demand different fixes.
Check calibration scope before the run, because an expired certificate produces offsets no coordinate edit will cure.

## Common mistakes
Editing program coordinates to remove a constant offset :: Verify fiducial coordinates and calibration first, then decide whether the program or the machine is wrong.
Judging placement from a total offset number alone :: Read X, Y and rotation separately, because a passing magnitude can hide a failing rotation.
Accepting a part-number check as program verification :: Verify fiducial origin, rotation and installed nozzle against the board, not only the BOM.

## Glossary
Global fiducial :: A board or panel reference mark used to establish origin, scale and rotation for the whole board.
Local fiducial :: A reference mark near a fine-pitch area that compensates local distortion or warpage.
Vision calibration :: The established relationship between camera pixel measurements and machine coordinates.
Skew :: Angular misalignment of a placed component against the board coordinate system.
