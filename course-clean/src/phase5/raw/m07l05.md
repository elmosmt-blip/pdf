## Why disposition language matters
In AOI, disposition language turns a visual or geometric call into a repeatable engineering statement. A second engineer should read the finding and reach the same accept, reject or rework decision without hearing the inspector's tone.

The statement names the object, the observed condition, the applicable workmanship class, the evidence and the verification status.

## Defect, condition and class
Workmanship vocabulary keeps three ideas apart. A defect is a nonconformance to the applicable requirement. A condition is the observable state that may or may not be a defect depending on class and criteria — insufficient solder, a lifted lead, tombstoning, a solder bridge. A class is the workmanship level, commonly IPC-A-610 Class 1, Class 2 or Class 3, which sets the acceptance threshold for that same condition.

## AOI output is evidence, not disposition
AOI indicates a suspected condition from height, area, shape, colour or position. It misses hidden defects and produces false calls from shadows, reflections and component tolerance.

Until measurement, microscopy, X-ray or manual inspection confirms it, say indicated or suspected, or say that it requires verification. Words that assert a defect outrun the evidence.

## A repeatable finding sentence
A useful finding has a fixed order: location, object, condition, evidence, standard or class, proposed action.

For example: "U7 pin 12: suspected insufficient solder fillet; AOI fillet height 0.18 mm; verify against IPC-A-610 Class 2 and paste deposit data." That sentence gives the next engineer where to look, what was measured, which class applies, and what to do next.

## Class changes what a condition means
A condition acceptable in general electronics may be unacceptable in a high-reliability assembly. IPC-A-610 Class 1, Class 2 and Class 3 describe increasing workmanship requirements, so the same fillet, component tilt or solder ball can be dispositioned differently.

State the class on the finding. Do not let the product name imply it.

## Disposition terms match the system
Workmanship acceptance is normally accept or reject against the applicable standard. A manufacturing disposition may add rework, scrap or use-as-is, and rework has to restore the assembly to the original acceptance criteria.

Rework and repair follow IPC-7711/7721 or the customer-approved equivalent, and the finding says whether rework is proposed or already performed.

## Handoff information
A handoff carries enough to reproduce the decision: panel or serial number, coordinate or reference designator, AOI program version, measured value, uncertainty or confidence, applicable standard and class, and verification method.

Where a number is process-based rather than standard-based, label it a process limit and cite the paste, stencil or AOI datasheet. AOI height uncertainty, for instance, may run around 0.02 mm to 0.05 mm, verified against the equipment datasheet.

## Key takeaways
Write the finding in a fixed order — location, object, condition, evidence, class, action — so a second engineer arrives at the same call.
Say suspected or indicated until measurement confirms the condition, because AOI output is evidence and not a verdict.
Name the class and the standard on every finding, since the same condition can pass in one class and fail in another.

## Common mistakes
Writing a finding that asserts a defect from an AOI call :: State it as suspected and say what verification is still required.
Leaving the class implicit in the product name :: Print the applicable IPC-A-610 class on the finding itself.
Quoting a process limit as if it were the workmanship standard :: Label it as a process limit and cite the datasheet behind it.

## Glossary
Condition :: An observable state that may or may not be a defect depending on the class and criteria applied.
Disposition :: The recorded decision on a nonconforming item: accept, reject, rework, repair, scrap or use-as-is.
Rework :: Processing that restores a nonconforming item to the original acceptance criteria.
Use-as-is :: A documented concession to accept an item that does not meet the stated requirement.
