## Define the symptom with measured data
Start with the observed defect, not a suspected cause.

Record product, lot, stage, time in seconds, operator, equipment, and the measured attribute: solder volume in cubic millimetres, component offset in millimetres, hole fill as a percentage.

Use a taxonomy that separates symptom families: insufficient solder, excess solder, misalignment, voiding, non-wet. The taxonomy has to stay stable across lots, or nothing can be compared later.

## Pareto by stage before root cause
Sort defect counts by process stage: paste print, placement, reflow, wave, inspection.

A Pareto by stage shows where the largest measured loss is, not where the most obvious cause is. A stage with few defects but high cost or high field risk stays visible anyway.

Use the stage Pareto to set containment priority and to decide where to collect the next data, not to name the culprit.

## Check measurement integrity first
A Pareto is only as good as the measurement behind it.

Verify the inspection method, the sample plan and the agreement between operators. For dimensional checks, confirm that the gauge resolution in millimetres is fine enough for the tolerance, and that measurement uncertainty is small against process variation.

For visual defects, use boundary samples and cross-check independent inspectors. Where disagreement is large, fix the measurement before sorting the data.

## Separate root cause, contributing causes and detection escape
The root cause is the process condition that, once removed, prevents recurrence under normal conditions.

Contributing causes make the defect more likely or more severe: paste viscosity drift, feeder wear, thermal profile variation in degrees Celsius, conveyor speed variation in millimetres per second. The detection escape explains why the defect was not found before shipment, such as a missing AOI program revision or a sampling plan that never covered the feature.

Each category gets its own action, and the report keeps them apart. A complete 8D report must address all three, because a corrected process with an open escape still ships defects.

## Containment must be measurable and time-bound
Containment protects the customer while the cause is being confirmed: quarantine, full inspection, rework, or a temporary process limit.

State the containment owner, the start time, the review interval and the exit condition. The exit condition rests on measured evidence, such as a clean inspection window or verified process capability, not on elapsed time alone.

## Corrective action changes the process
Corrective action removes the root cause and closes the detection escape.

Examples: changing the stencil design, updating feeder calibration, adding a profile check, modifying an AOI program. Each action has an owner, a due date and a verification method.

Verification should show that the action works under normal production conditions, and that the defect returns if the action is removed — which is the honest test of whether it was a cause.

## Closure with an effectiveness metric
Closure is not complete until the effectiveness metric is defined and measured.

A common metric is no escapes inside a defined verification window, with the window chosen from production volume and risk. Record the baseline defect rate, the post-action defect rate and the inspection method used.

If the metric is not met, reopen the analysis rather than closing the report.

## Key takeaways
Fix the measurement before reading the Pareto, because inspection noise sorts into a chart like real signal.
Set the containment exit on evidence, since a time-based exit simply ends attention.
Prove the cause by removing the action, because a fix that cannot be reversed cannot be demonstrated.

## Common mistakes
Reading the stage Pareto as a diagnosis :: Use it to choose the next measurement, since it ranks symptoms and not causes.
Closing on a clean week of output :: Measure the metric across a defined window, because a short quiet period proves little.
Keeping a containment in place with no exit condition :: Define the evidence that ends it, because permanent containment becomes the process.

## Glossary
Stage Pareto :: Defect counts sorted by the process stage where they were detected or attributed.
Boundary sample :: A physical specimen showing the limit of acceptability, used to align inspectors.
Detection escape :: The third cause category of an 8D: why the defect passed the inspection or test meant to catch it.
Process capability :: How well a process holds its specification, stated as a measurable index.
