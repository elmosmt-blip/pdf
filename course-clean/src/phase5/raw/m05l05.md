## Pre-production placement verification
Before production, verify that the placement program, component library, feeder setup, nozzle selection and machine calibration represent the approved design and process.

The check has to prove the machine can place the right components, in the right orientation, at the right coordinates, with acceptable accuracy. Run a dry run or offline simulation first, then a pre-production sample under controlled conditions.

## Component library setup
The component library holds package geometry, body size, pin or pad pitch, polarity, rotation, pick point, nozzle, feeder type, vision settings and placement tolerance. Verify each field against the component datasheet and a physical sample.

On polarised parts, confirm the library polarity matches the silkscreen and the feeder orientation. On fine-pitch packages, confirm that tape, reel or feeder geometry does not obscure the pick point and the vision reference.

## Program and setup checks
Check the coordinate origin, fiducial pattern, panel offsets, mirror settings, units, component side and layer assignment.

Confirm the feeder map matches the physical feeders, that nozzles suit component size and clearance, and that the program commands no collision with panel edges, connectors or tall components. Review the sequence for pickup order, nozzle changes and vision cycles.

## Calibration status before release
Placement accuracy depends on machine calibration, vision calibration, feeder calibration, nozzle condition and conveyance alignment.

Before release, confirm that required calibration certificates exist, are traceable, sit inside the interval set by the equipment manufacturer or your calibration plan, and are supported by verification results. A certificate that is missing, expired or outside the required environmental or usage conditions leaves the setup unverified until calibration is complete and recorded.

## Pre-production sample inspection
Run a sample and inspect for missing components, wrong components, polarity and rotation errors, tombstoning and poor seating, using AOI, X-ray or manual inspection as the case needs.

Measure placement coordinates against the program and compare the deviation with the tolerance from the equipment datasheet or the process capability study. Record the measured values, the method, the operator and the disposition.

## Acceptance criteria and release
Define pass and fail before the sample runs. Criteria cover placement coordinate tolerance, polarity, rotation, missing or wrong components, and calibration status, taken from the paste, feeder, nozzle and placement equipment datasheets and confirmed against your own capability.

Release production only when program, setup, calibration and sample inspection all meet the defined criteria.

## Change control and records
Any change to the program, component library, feeder, nozzle, panel, fiducial or calibration status repeats the relevant verification steps.

Store the program version, library version, calibration records, sample results and approval with the production record, so the setup stays traceable and containment is possible when a defect turns up later.

## Key takeaways
Verify the library against a physical sample, because a polarity or rotation field copied from a datasheet can still disagree with the reel.
Treat a missing or expired calibration as a failed setup, whatever the sample deviation shows.
Record program and library versions with the sample result, so a later defect can be traced to the configuration that made it.

## Common mistakes
Releasing on a good sample while calibration has expired :: Confirm the certificate first, since the sample may pass today and fail after an axis drift tomorrow.
Checking part numbers without checking pick point and vision reference :: Confirm both for fine-pitch parts, because tape or feeder geometry can obstruct them.
Skipping reverification after a feeder change :: Repeat the polarity and rotation checks, which is exactly where a feeder change goes wrong.

## Glossary
Component library :: The stored geometry, orientation and handling data the machine uses for each part number.
Feeder map :: The table that assigns each part number to a physical feeder slot.
Pre-production sample :: A controlled first run inspected before the line is released.
Calibration interval :: The period within which an instrument or axis must be recalibrated.
