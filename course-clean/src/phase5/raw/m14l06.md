## Closing the loop means changing the control system
A corrective action is not complete when the line returns to normal output.

It is complete when the learning is written into the PFMEA, the control plan, the auditor checklist and the change-control record.

The PFMEA records the failure mode, cause, detection method and risk priority. The control plan records the process parameter, specification, measurement method, sample size, frequency and reaction plan. The checklist asks whether the control is being executed, and the change record shows who approved it and when.

## Change control against uncontrolled drift
Change control is the route by which a process change is proposed, reviewed, approved, implemented, verified and closed.

In electronics assembly the changes include paste type, stencil aperture, reflow profile, wave solder temperature, flux density, conveyor speed, component substitution, feeder change, nozzle change, placement program revision and inspection criteria.

A change is controlled when it can affect fit, form, function, reliability or the acceptance decision. That covers most of the list above.

## PFMEA should reflect the current process
The PFMEA is a living risk document.

After an investigation, update the failure mode when a new cause is found, update the cause when the root cause differs from the original assumption, and update the detection method when the current inspection cannot reliably find the defect.

Update severity, occurrence or detection ratings only when evidence justifies it. A rating changed to make the chart look better is worse than no rating at all.

## Control plan with measurable controls
A control plan cannot say only that the operator checks quality.

It states what is checked, how often, with what method, against what limit, and what happens when the result falls outside specification.

For paste printing that means stencil cleanliness, paste viscosity or rheology per the paste datasheet, print alignment, paste height, paste volume and post-print inspection. For reflow it means zone temperatures, conveyor speed, atmosphere and profile verification.

## Auditor checklist
The auditor checklist asks whether the control exists and whether it is followed.

Useful questions: is the current revision of the control plan available at the station, are measured values recorded at the required frequency, are out-of-limit results handled per the reaction plan, are calibration labels valid, is rejected material segregated, and are change-control records complete?

A checklist that only asks whether a document exists audits the filing cabinet.

## A documented change-control package
A practical package contains the problem statement, defect data, root cause, proposed change, affected documents, risk assessment, verification plan, implementation date, responsible owner and closure evidence.

For an SMT example, a new paste lot causing insufficient solder on fine-pitch QFN pads brings in paste lot traceability, a stencil design review, a reflow profile comparison against IPC-7530, first-article results and the updated control plan.

## Acceptance criteria and rework rules
When updating inspection criteria, use the applicable acceptance standard and the customer or internal specification.

IPC-A-610 gives the acceptance classes and visual criteria for solder joints, components and cleanliness, and IPC-7711/7721 gives the rework and repair methods.

Where a change affects rework, the rework instruction changes with it, so the new criteria and the old method do not sit side by side in the same document set.

## Close with verification, not only approval
After implementation, verify that the defect rate has fallen and that no new failure mode has appeared.

Verification may use first-article inspection, in-process data, final inspection data, field return data, reliability test data or audit findings.

A temporary change carries an expiry date or a condition for permanent adoption in the change record itself, so it cannot become permanent by neglect.

## Key takeaways
Write the learning into the documents the line follows, because an action that lives only in the 8D changes nothing.
Attach a measurable control to every change, since "operator checks" is not a control.
Verify the defect rate after implementation, because a new failure mode often arrives with the fix.

## Common mistakes
Approving a change and skipping the control plan update :: Update the plan and the checklist, because the station follows the plan.
Leaving a temporary change in place indefinitely :: Set an expiry date, since temporary settings become permanent by default.
Editing PFMEA ratings to reflect the hoped-for improvement :: Rate from evidence, because the rating drives the next risk decision.

## Glossary
Control plan :: The document stating what is measured, how often, against what limit, and the reaction when it fails.
PFMEA :: Process failure mode and effects analysis, the living risk record for the process.
Reaction plan :: The defined response when a measured value falls outside its limit.
First-article inspection :: A full check of the first unit produced after a change.
