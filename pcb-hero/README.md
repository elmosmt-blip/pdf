# OpenTrace — PCB-шапка (концепт)

Шапка в визуальном языке [smtinsider.com](https://www.smtinsider.com/), собранная как **печатная плата**:
тёмный сланец `#0D1117`, сигнальный teal `#53d1cc`, IBM Plex Sans/Serif/Mono,
панели `rgba(15,23,34,.78)` с радиусом 28px и границей `rgba(146,165,185,.18)`.
Центр композиции — **BGA‑256**: 16×16 шариков, рентген-кристалл, fan-out на подложке.

## Запуск

```bash
python3 -m http.server 8080   # из папки pcb-hero
# http://localhost:8080/
```

Без сборки и внешних запросов: шрифты лежат в `assets/fonts`.

## Структура

| Файл | Назначение |

| `index.html` | Разметка, SVG-кристалл, HUD-панели, BGA-сетка |

## Управление

- **Наведение на BGA** — рентген: кристалл, wire-bond fan-out, подложка.
- **Клик / Enter** — закрепить рентген, `Esc` — снять.
- **Мышь по плате** — параллакс и наклон корпуса.
- **`/`** — фокус в поиске по нетлисту.

## Технические детали

- Детерминированный RNG (`mulberry32`) — рисунок платы одинаков при каждой загрузке.
- Трассы под маской: широкий мягкий halo + тонкая металлическая жила; 45° по раскладке `straight → 45° → pad`.
- Пады ENIG с бликом, переходные с золочёным кольцом и тёмным сверлением, кромка FR‑4, шелкография белой краской.
- Компоненты рисуются как объёмные: единый источник света сверху-слева (`LIGHT`), экструзия боковых стенок (`block3D`), мягкая контактная тень на `feGaussianBlur` (`#partShadow`), металлические терминации с блик-гранью и тёмной пяткой, галтели припоя, лазерная маркировка (`103`, `OT256`, `OT‑S25Q`).
- Корпуса: `smdBody` (0402/0603/0805), `qfn` (тепловая площадка, выводы из-под корпуса, pin‑1), `soic` (gull‑wing выводы с тенью), `tantalum` (жёлтый компаунд, полярность), `inductor` (обмотка), монтажные отверстия, фидуциалы, тест-пойнты.
- Импульсы — `stroke-dasharray` + `animateMotion`, без библиотек.
- Учтены `prefers-reduced-motion`, `:focus-visible`, `aria-pressed` на BGA, тач-таргеты ≥ 38px.

## Вращение BGA

- **Авто-качание** — пока курсор вне чипа, корпус сам медленно покачивается по Y (±40°) и кивает по X (±8°); любой контакт с мышью ставит качание на паузу (`is-spinning`, переход отключается).
- **Перетаскивание мышью** — корпус вращается по X и Y с инерцией и плавно возвращается к посадочному наклону. Наклон ограничен ±34° по X, ±55° по Y от посадочной позы — так торец не «схлопывается» в плоскую плиту.
- **Стрелки ← → ↑ ↓** (когда чип в фокусе) — пошаговый поворот.
- **Клик** — рентген-режим; жест перетаскивания клик не вызывает (`suppressClick`).
- Рентген включается по наведению и закрепляется кликом; во время активного перетаскивания оверлей гасится (`is-dragging`), чтобы был виден физический корпус, а после отпускания — возвращается.
- Под корпусом на плате нарисована настоящая посадочная площадка: 256 контактных площадок, dog-bone escape-трассы с переходными отверстиями, двор и шелкография `U1 · SOCKET` (`.chip__footprint`, генерируется в `board.js`, секция 7b).
- Тень — это мягкое овальное пятно (`border-radius: 50%` + blur). Прямоугольная тень под корпусом читалась как чёрная плита на текстолите.
- Толщина корпуса — это рим `.chip__edge` с градиентами кромок; его интенсивность считается от угла (`--edge`), поэтому торец читается как кромка, а не как чёрная плита.
- Освещение шариков считается в экранных координатах: блик не «прилипает» к корпусу при повороте.
