# OpenTrace — PCB-шапка (концепт)

Шапка в визуальном языке [smtinsider.com](https://www.smtinsider.com/), собранная как **печатная плата**:
тёмный сланец `#0D1117`, сигнальный teal `#53d1cc`, IBM Plex Sans/Serif/Mono,
панели `rgba(15,23,34,.78)` с радиусом 28px и границей `rgba(146,165,185,.18)`.
Центр композиции — **BGA‑256**: 16×16 шариков, рентген-кристалл, fan-out на подложке.

## Запуск

```bash
python3 -m http.server 8080   # из папки pcb-hero
# http://localhost:8080/
```

Без сборки и внешних запросов: шрифты лежат в `assets/fonts`.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка, SVG-кристалл, HUD-панели, BGA-сетка |
| `assets/css/style.css` | Токены SMTInsider DS v2, состояния, адаптив |
| `assets/js/board.js` | Генератор платы: трассы 45°, SMD/QFN/SOIC/танталы, переходные, шелкография, импульсы |
| `assets/fonts` | IBM Plex Sans / Mono / Serif (OFL) |

## Управление

- **Наведение на BGA** — рентген: кристалл, wire-bond fan-out, подложка.
- **Клик / Enter** — закрепить рентген, `Esc` — снять.
- **Мышь по плате** — параллакс и наклон корпуса.
- **`/`** — фокус в поиске по нетлисту.

## Технические детали

- Детерминированный RNG (`mulberry32`) — рисунок платы одинаков при каждой загрузке.
- Трассы под маской: широкий мягкий halo + тонкая металлическая жила; 45° по раскладке `straight → 45° → pad`.
- Пады ENIG с бликом, переходные с золочёным кольцом и тёмным сверлением, кромка FR‑4, шелкография белой краской.
- **Пассив — один силуэт, а не набор накладок.** Тело и оба металлизированных торца описывает ОДИН градиент (`partDark` для резистора, `partWarm` для MLCC, `partTant` для тантала), у которого стопы заданы долями длины: металл → тень шва → керамика → шов → металл. Поэтому торцы не могут «съехать» относительно корпуса и не читаются наклейками, а одна и та же пара градиентов обслуживает и 0402, и 0805. Сверху — один общий световой проход (`partLight`: светлая кромка сверху, роллофф снизу) на весь кирпичик.
- Припой не выступает за контур: галтель `wick` — это волосяная полоска того же металла, вписанная в торец, а медная площадка видна только узкой полоской ENIG за кромкой торца.
- **Толщина без смены силуэта.** `block3D` больше не рисует смещённую копию корпуса (это давало «две карточки» у SOIC/QFN/индуктора). Теперь это один прямоугольник: подсвеченная верхняя грань и полоса боковой стенки в пределах того же контура, на стороне, отвёрнутой от лампы.
- Материал торцов — тусклое олово после оплавления (`capTinMatte` / `capWarmMatte`), а не хром: яркие белые полосы читались как напечатанные метки.
- Мягкая контактная тень на `feGaussianBlur` (`#partShadow`), галтели припоя, лазерная маркировка (`103`, `OT256`, `OT‑S25Q`).
- Компоненты рисуются как объёмные: единый источник света сверху-слева (`LIGHT`).
- Корпуса: `smdBody` (0402/0603/0805), `qfn` (тепловая площадка, выводы из-под корпуса, pin‑1), `soic` (gull‑wing выводы с тенью), `tantalum` (жёлтый компаунд, полярность), `inductor` (обмотка), монтажные отверстия, фидуциалы, тест-пойнты.
- Импульсы — `stroke-dasharray` + `animateMotion`, без библиотек.
- Учтены `prefers-reduced-motion`, `:focus-visible`, `aria-pressed` на BGA, тач-таргеты ≥ 38px.

## Вращение BGA

- **Авто-переворот со свипом** — пока курсор вне чипа, корпус одновременно крутится вбок (yaw ±46° на своём такте `sin(t/4200)`) и переворачивается от посадочного наклона до 180° и обратно (`(1-cos(t/8600))/2`, цикл ≈ 54 с). Разные такты не дают двум движениям слипнуться в однообразный маятник. Скорость гасится в крайних точках — рывка нет ни на старте, ни в верхней точке. Любой контакт с мышью ставит на паузу (`is-spinning`).
- **Перетаскивание мышью** — свободное вращение в обе стороны: yaw не ограничен (корпус можно крутить вокруг вертикальной оси на любой угол), наклон по X — в пределах ±180°. Есть инерция и возврат к посадочной позе.
- **Порядок поворотов** — `rotateY` затем `rotateX`: сначала корпус поворачивается вокруг своей вертикальной оси, потом наклоняется, поэтому гравировка на крышке никогда не оказывается зеркальной.
- **Стрелки ← → ↑ ↓** (когда чип в фокусе) — пошаговый поворот.
- **Клик** — рентген-режим; жест перетаскивания клик не вызывает (`suppressClick`). Рентген включается по наведению и закрепляется кликом; во время активного перетаскивания оверлей гаснет (`is-dragging`), после отпускания — возвращается.
- **Геометрия корпуса.** Это настоящая коробка, а не наклейка: грань с шариками на `z = 0`, лицевая крышка на `z = --thick` с разворотом `rotateX(180deg)`, между ними четыре торца `.chip__side`. Каждый торец — грань куба `1 × 1 × --thick`, навешенная на своё ребро через `transform-origin`, с запасом 1px по плоскости, чтобы углы сходились без щелей. Толщина — 8.5% стороны корпуса (для 17 мм BGA это ≈1.45 мм).
- **Лицевая сторона** — матовая заливка эпоксидки, лазерная надпись `smtinsider` (IBM Plex Sans), строка `OT-256 · BGA-256 · 0.80P`, партия `LOT 2641 · TW · 2026`, метка первого вывода и логотип-осциллограмма.
- **Материал крышки** — чёрный трансферный компаунд (типа Sumitomo EME-G770). Слои: базовый цвет, следы течения смолы + микротекстура (`feTurbulence`), ключевой свет, затенение к дальним краям и подсвеченная фаска. След выталкивателя убран: на тёмной матовой крышке он читался грязным пятном, а не технологическим отпечатком. Надпись — травление чуть светлее смолы, без свечения.
- **Свет живёт в комнате, а не на детали.** Направление ключевого света (`LIGHT` в `board.js`) проецируется в систему координат крышки на каждом кадре: блик скользит по плоскости, фаска загорается только на повёрнутом к лампе ребре, а торцы считаются по собственной нормали (ламберт). Поэтому при вращении блики не «приклеены» к граням.
- **Контакт с платой** — затемнение по периметру нижней грани (`.chip__face--bottom::after`) и по каждому торцу (`.chip__side::after`): у впаянного BGA зазор ~0.15 мм читается почти чёрным.
- **Толщина** меряется в `board.js` (`syncThickness` + `ResizeObserver`) и пишется в `--thick` как пиксельная длина: 8.5% стороны корпуса. CSS не умеет вывести это из отрендеренной ширины внутри `var()`, поэтому пропорция держится скриптом.
- **Затухание на скользящем угле** — `--ball-lit` считается от косинуса между нормалью грани и взглядом; шарики и фильтр рентгена умножаются на него, поэтому на рёбре поле уходит в тень, а не висит рядами ярких точек.
- **Рентген видит сквозь ламинат** — в `.chip.is-xray` торцы гасятся, иначе они перекрывают кристалл.
- Под корпусом на плате нарисована настоящая посадочная площадка: 256 контактных площадок, dog-bone escape-трассы с переходными отверстиями, двор и шелкография `U1 · SOCKET` (`.chip__footprint`, генерируется в `board.js`, секция 7b).
- Тень — мягкое овальное пятно (`border-radius: 50%` + blur). Прямоугольная тень под корпусом читалась как чёрная плита на текстолите.
- Освещение шариков считается в экранных координатах: блик не «прилипает» к корпусу при повороте.
