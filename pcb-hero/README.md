# OpenTrace — PCB-шапка (концепт)

Маркетинговая шапка, собранная по принципу openrouter.ai, но как **печатная плата**:
сдержанная навигация со встроенным поиском-«сокетом», центрированный hero,
метрики, а главное — стеклянные панели-компоненты, сходящиеся трассами в одну точку.
Точка здесь — **BGA‑256**: 16×16 шариков, рентген-кристалл, фан-аут на подложке.

## Запуск

Открыть `index.html` напрямую или поднять любой статический сервер:

```bash
python3 -m http.server 8080
# http://localhost:8080/pcb-hero/
```

Сборка не нужна: только HTML/CSS/JS, шрифты лежат локально в `assets/fonts`.

## Что где

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка, SVG-кристалл, HUD-панели, BGA-сетка |
| `assets/css/style.css` | Токены маски/меди/ENIG, все состояния и адаптив |
| `assets/js/board.js` | Генератор платы: трассы 45°, SMD, QFN, переходные, шелкография, импульсы |
| `assets/fonts` | Inter Tight / Inter / JetBrains Mono (OFL/Apache) |

## Управление

- **Наведение на BGA** — рентген: кристалл, wire-bond фан-аут, подложка.
- **Клик / Enter** — закрепить рентген, `Esc` — снять.
- **Движение мыши по плате** — лёгкий параллакс и наклон корпуса.
- **`/`** — фокус в поиске по нетлисту.

## Технические детали

- Трассы строятся детерминированным RNG (`mulberry32`) — рисунок одинаков при каждой загрузке.
- Шарниры на 45°: раскладка `straight → 45° → pad`, как в реальном fanout.
- Импульсы — `stroke-dasharray` + `animateMotion` по контуру трассы, без библиотек.
- Учтены `prefers-reduced-motion`, `:focus-visible`, `aria-pressed` на BGA.
- Внешних запросов нет: полный офлайн.
